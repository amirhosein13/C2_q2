# تسمه‌نقاله

کارخانه‌ی «جمع‌کن» از یک سالن مستطیلی شکل تشکیل شده که کفِ آن به صورت یک جدول $N \times M$ از کاشی‌ها است. سطرهای جدول از بالا به پایین با $0$ تا $N-1$ و ستون‌های آن از چپ به راست با $0$ تا $M-1$ شماره‌گذاری شده‌اند. کاشیِ سطر $i$ و ستون $j$ را با $(i, j)$ نشان می‌دهیم.

در هر لحظه ممکن است یک بسته روی هر کدام از کاشی‌ها ظاهر شود و هدف این است که همه‌ی بسته‌ها، فارغ از این‌که کجا ظاهر شده‌اند، به کاشیِ گوشه‌ی بالا-راست، یعنی $(0, M-1)$، برسند. برای این کار، روی هر کاشی به جز $(0, M-1)$ یک تسمه‌نقاله نصب می‌شود که جهت آن یکی از چهار جهتِ بالا (`U`)، راست (`R`)، پایین (`D`) یا چپ (`L`) است. بسته‌ای که روی یک تسمه‌نقاله قرار دارد، به کاشیِ مجاور در جهتِ آن تسمه منتقل می‌شود.

یک **طرح** را **معتبر** می‌گوییم اگر هر بسته، از هر کاشی‌ای که شروع کند، پس از تعداد متناهی حرکت به کاشیِ $(0, M-1)$ برسد و در این مسیر هرگز از جدول خارج نشود.

انبار کارخانه دقیقاً $U$ تسمه‌ی رو به بالا، $R$ تسمه‌ی رو به راست، $D$ تسمه‌ی رو به پایین و $L$ تسمه‌ی رو به چپ دارد و باید از **همه‌ی** آن‌ها استفاده شود؛ یعنی $U + R + D + L = N \cdot M - 1$.

شما باید برای چند سالن مختلف، یک طرحِ معتبر بیابید که دقیقاً از همین تعداد تسمه‌ از هر نوع استفاده کند، یا تشخیص دهید که چنین طرحی وجود ندارد.

## جزئیات پیاده‌سازی

شما باید تابع زیر را پیاده‌سازی کنید:

```
std::vector<std::string> design(int N, int M, int U, int R, int D, int L)
```

* $N$ و $M$: تعداد سطرها و ستون‌های جدول.
* $U$، $R$، $D$ و $L$: تعداد تسمه‌ها از هر جهت.
* اگر طرحِ معتبری وجود ندارد، این تابع باید یک آرایه‌ی **خالی** برگرداند.
* در غیر این صورت باید آرایه‌ای از $N$ رشته برگرداند که هر کدام دقیقاً $M$ کاراکتر دارند؛ کاراکترِ $j$-اُمِ رشته‌ی $i$-اُم وضعیتِ کاشیِ $(i, j)$ را مشخص می‌کند. کاراکترِ کاشیِ $(0, M-1)$ باید `*` باشد و هر کاراکترِ دیگر یکی از `U`، `R`، `D` و `L`. اگر چند طرحِ معتبر وجود دارد، هر کدام پذیرفته می‌شود.
* این تابع در هر اجرا $T$ بار (برای $T$ سالنِ مستقل) فراخوانی می‌شود.

برنامه‌ی شما نباید چیزی در خروجی استاندارد بنویسد یا از ورودی استاندارد بخواند؛ در غیر این صورت ممکن است پاسخ شما نادرست ارزیابی شود.

## محدودیت‌ها

* $1 \le T \le 100\,000$
* $1 \le N, M$ و $N \cdot M \le 100\,000$
* $0 \le U, R, D, L$ و $U + R + D + L = N \cdot M - 1$
* مجموعِ $N \cdot M$ در همه‌ی فراخوانی‌های یک اجرا حداکثر $100\,000$ است.

محدودیت زمان: ۱ ثانیه — محدودیت حافظه: ۲۵۶ مگابایت

## زیرمسئله‌ها

| زیرمسئله | امتیاز | محدودیت‌های اضافه |
|:-:|:-:|:--|
| ۱ | ۹ | $N \cdot M \le 10$ و $T \le 100$ |
| ۲ | ۱۱ | $D = L = 0$ |
| ۳ | ۱۷ | $N \le 2$ |
| ۴ | ۲۳ | $U \le N - 1$ و $R \le M - 1$ |
| ۵ | ۴۰ | بدون محدودیت اضافه |

## مثال‌ها

### مثال ۱

```
design(4, 3, 5, 3, 1, 2)
```

یک پاسخِ درست، آرایه‌ی زیر است:

```
["DR*", "RRU", "ULL", "UUU"]
```

در این طرح $5$ تسمه‌ی `U`، $3$ تسمه‌ی `R`، یک تسمه‌ی `D` و $2$ تسمه‌ی `L` به کار رفته است. برای نمونه، بسته‌ای که روی $(2, 2)$ ظاهر شود این مسیر را طی می‌کند:

$$(2,2) \to (2,1) \to (2,0) \to (1,0) \to (1,1) \to (1,2) \to (0,2)$$

```
design(1, 2, 0, 1, 0, 0)
```

تنها پاسخِ درست `["R*"]` است.

### مثال ۲

```
design(3, 3, 0, 0, 0, 8)
```

هر بسته‌ای که در ستونِ $0$ ظاهر شود باید جایی از ستونِ $0$ به ستونِ $1$ برود، اما هیچ تسمه‌ی `R`ای وجود ندارد. پس طرحِ معتبری وجود ندارد و تابع باید آرایه‌ی خالی برگرداند.

```
design(2, 2, 0, 2, 0, 1)
```

بسته‌ای که روی سطرِ $1$ ظاهر شود هرگز به سطرِ $0$ نمی‌رسد، چون هیچ تسمه‌ی `U`ای نداریم. پس پاسخ آرایه‌ی خالی است.

```
design(1, 1, 0, 0, 0, 0)
```

پاسخ `["*"]` است.

## گریدر نمونه

گریدر نمونه ورودی را با قالب زیر می‌خواند:

* سطر ۱: $T$
* سطر $1 + t$ به ازای هر $1 \le t \le T$: شش عدد `N M U R D L` برای فراخوانیِ $t$-اُم

گریدر نمونه برای هر فراخوانی، ابتدا یک سطر شامل $k$، یعنی تعداد رشته‌های آرایه‌ی برگردانده‌شده، و سپس آن $k$ رشته را هر کدام در یک سطر چاپ می‌کند. اگر یکی از رشته‌ها خالی باشد یا کاراکتری غیر از کاراکترهای قابل‌چاپ (بدون فاصله) داشته باشد، به جای همه‌ی این‌ها فقط $-1$ چاپ می‌شود.

توجه کنید که گریدر نمونه درستیِ طرح را بررسی **نمی‌کند**؛ گریدرِ داوری از همین قالب استفاده می‌کند و سپس طرح به طور کامل بررسی می‌شود.
